# NJFU智慧猫娘

一个能像玩家一样进入 Minecraft 的 AI 猫娘伙伴：陪你冒险、听你在聊天栏的吩咐干活、和你聊天互动。大脑可以是 Claude（直接调用接口，或者由 Claude Code 会话来“附身”），也可以是 GPT、DeepSeek 等 OpenAI 兼容接口。

- 支持新版本服务器（包括 26.2 这样 mineflayer 还没支持的版本）：自动经 ViaProxy 转换协议。
- 支持装了 Fabric API 的服务器和局域网世界：自动完成 Fabric 注册表同步握手。
- 可选的人物面板模组：右键她直接打开她的背包，Shift+右键弹出功能菜单。

## 她能做什么

- **聊天**：聊天里带上「猫娘」就能叫她，私聊也行。中文口语，偶尔带「喵」。
- **干活**：采集、合成（自己规划合成树）、熔炼、存取箱子、运送物资、跟随、护卫、打怪、建造、驯服动物。
- **自己动**：没事时陪在主人身边；捡掉落物；缺装备和食物时去箱子里拿，闲着时翻看附近的箱子；背包快满时扔垃圾（不扔礼物和附魔的东西）；受伤时吃东西回血；离太远自动传送回来。
- **战斗**：跳劈暴击、盾牌格挡、船困怪、弓箭和雪球自动算弹道、岩浆桶先烫再砍、被围住时水桶冲开或垫方块躲上去、打斗间隙吃东西喝药水、不死图腾换到副手……只剩 1 滴血才撤。战斗模式分普通 / 困难 / 极限 / 作弊，发 `#战斗模式` 切换。
- **出行**：被困住才垫方块搭路；从高处掉下来落地前倒水、滑翔或放船；有鞘翅和烟花能飞；穿传送门；和你一起坐船、骑马、坐矿车。
- **懂规矩**：不打挂了命名牌的生物、刷怪机器里的生物和禁战区里的生物；/ 命令分级管理，只替主人执行管理员命令。
- **红石与建造**：排查红石故障；按方块状态建造；照投影（Litematica）原理图建造。建造前自动备料：背包够就直接建，箱子里够会先问你，都不够就自己采集、合成。
- **查资料**：本地游戏数据（配方、来源、方块和生物）、Minecraft 中文 Wiki；Claude API 模式还能联网查 MC百科。用 /locate 找结构并附 Chunkbase 地图链接。
- **PVP 决斗**：简单、普通、困难Ⅰ～Ⅵ、作弊Ⅰ～Ⅵ，装备从铁套到顶级附魔下界合金，招式从普通砍到剑斧切换、蜘蛛网、鞘翅俯冲、末影珍珠瞬移、末影水晶和 TNT（放好后拉开距离再射爆）。装备都是临时的，打完收回，默认给对手也穿一套。
  - 默认在原地正上方现搭一个 100×100 的空中决斗场，搭之前会确认不盖住任何方块，打完拆掉并送你回原处。
  - 所有难度都强制锁 1 滴血，谁都不会被打死。一局最长 15 分钟（作弊档 30 分钟），屏幕上方有倒计时，随时可以 `#认输`；别的玩家发 `#观战` 可以以旁观者模式去看。
- **互动**：好感度、摸头、抱抱、跳舞、坐下、捡木棍、猜拳、猜数字、钓鱼；有人上床时问要不要一起睡，答应了就陪到天亮；上线问候、死亡关心、进度祝贺。
- **在游戏里许愿和设置**：主人发 `#需求 …` 提新功能（Claude Code 模式下由后台处理，见 [CLAUDE.md](CLAUDE.md)），发 `#设置` 直接开关她的各种行为。

## 工作原理

```
你的 Minecraft（例如 26.2 局域网世界）
        ▲
        │  26.2 协议
   ViaProxy（协议转换，自动启动）
        ▲
        │  26.1 协议
   猫娘本体（Node.js + mineflayer）── 控制接口 127.0.0.1:3777 ── 命令行 / Claude Code
        │
   大脑（四选一）：Claude API ／ OpenAI 兼容接口 ／ Claude Code 会话 ／ 不思考只挂机
```

猫娘本体负责进服、走路、打怪、干活和快捷命令；“大脑”负责听懂你随口说的话、决定怎么回、要做什么。

## 第一次安装

下面按“一台什么都没装的 Windows 电脑、从 GitHub 下载压缩包”来写。整个过程只需要双击 `start.bat`，缺什么它会告诉你，能自动装的会先问你要不要装。

### 1. 下载

在 GitHub 项目页点绿色的 **Code** 按钮 → **Download ZIP**，解压到一个固定的文件夹，例如 `D:\NJFU-Neko`。路径里有中文、空格都没关系。以后她的配置、记忆都存在这个文件夹里，别解压到临时目录。

### 2. 双击 start.bat

第一次双击时，Windows 可能提示“Windows 已保护你的电脑”（从网上下载的脚本都会这样）：点 **更多信息** → **仍要运行**。

它会按顺序检查和准备：

| 步骤 | 已经有了 | 还没有 |
|---|---|---|
| **Node.js 20+** | 自动找到：官方安装包、fnm、nvm-windows、Volta 装的都认 | 问你要不要用 winget（Windows 10/11 自带）自动安装长期支持版；没有 winget 就打开官网下载页，装好后重新双击 |
| **依赖** | 跳过 | 自动 `npm install`（第一次一两分钟）；连不上 npm 官方源时自动换国内镜像重试 |
| **config.toml** | 跳过 | 问你 4 个问题自动生成：服务器地址、端口、你的游戏名、选哪种大脑（见[下一节](#选择大脑四种模式)）；要填 API Key 时，输入的内容不会显示在屏幕上 |
| **Java 17+**（ViaProxy 要用） | 自动找电脑上已有的，包括 Minecraft 启动器自带的 Java，找到了写进 config.toml | 问你要不要用 winget 自动安装 Temurin 21；也可以到 <https://adoptium.net/zh-CN/> 手动下载。只连 1.21.x 以前的服务器可以不装 |
| **ViaProxy** | 跳过 | 自动从 GitHub 下载；下载不下来会告诉你手动下载后放到哪 |

都准备好后她就启动了。以后每次双击 `start.bat` 也会先检查一遍，都准备好了一秒就跳过。

> 不用 Windows、或者想手动来：先装好 [Node.js](https://nodejs.org/zh-cn) 20+ 和 Java 17+，在项目文件夹里运行 `npm run setup`（同样会问答生成配置），再用 `npm start` 启动。

### 3. 以后想改配置

用记事本打开 `config.toml`，每一项都有中文注释。常用的几项：

| 位置 | 是什么 |
|---|---|
| `[server]` `host` `port` | 服务器地址和端口。局域网世界填 `127.0.0.1` 和开放时显示的端口 |
| `[account]` `username` `auth` | 她的名字（默认 `NJFU_Neko`）；离线账号 `auth = "offline"`，正版服务器用 `"microsoft"` |
| `[chat]` `owners` | 主人名单，例如 `["你的游戏名"]`。留空表示所有人都是主人，上服务器前一定要填 |
| `[brain]` `mode` | 大脑模式，见[下一节](#选择大脑四种模式) |
| `[viaproxy]` `java` | 用哪个 Java。一般自动填好；想换就写 java.exe 的完整路径，例如 `"D:/Java/bin/java.exe"` |

没写的项自动用 `config.example.toml` 里的默认值。改完要重启她才生效；游戏里用 `#设置` 改的立刻生效。

### 4. （可选，推荐）安装人物面板模组

`mod/dist/njfu-neko-panel-*.jar` 是一个很小的 Fabric 模组（目前适配 Minecraft 26.2，需要 Fabric API）。先关掉游戏，再在项目文件夹里运行：

```bash
npm run install-mod -- --game "你的.minecraft/versions/版本名"
```

它会把新版本放进这个版本的 `mods` 文件夹，旧版本挪到 `runtime/trash`（不删除）。也可以手动把 jar 复制进 `mods`。重新打开游戏生效。装了之后：

- **右键猫娘**：打开她的人物面板（盔甲、副手、背包、快捷栏），直接拖动就能拿放。只有主人能拿放，其他人只能看（在游戏目录的 `config/njfu_neko_panel.json` 里设置）。
- **Shift+右键**：她给你弹出功能菜单，按钮点一下就生效。
- 她执行命令时不在管理员聊天栏里留灰色提示；决斗时能锁 1 滴血、保管你的背包、让附近的爆炸不破坏方块；决斗中右键她不会打开背包。

单人和局域网世界装在自己的游戏里就行；服务器要装在服务器上。自己编译：`npm run build-mod -- --game "<.minecraft>/versions/<版本名>" --jdk <JDK 25+ 目录>`（不需要 Gradle）。

### 5. 准备游戏

**局域网单人世界**

1. 在游戏里“对局域网开放”：**正版验证选“禁用”**（她是离线账号），**允许命令**打开，记下端口。装了 mcwifipnp 可以固定端口，不用每次改配置。
2. 端口和 `config.toml` 的 `[server] port` 不一样时改过来，再重启她。
3. 她进来后，在聊天栏输入 `/op NJFU_Neko` 给她管理员权限：说话变好看，能传送、决斗、弹菜单。

**服务器**

- 先确认服务器规则允许机器人，并填好 `[chat] owners`。
- 正版服务器：`[account] auth = "microsoft"`，第一次启动按提示在浏览器登录微软账号（不用写密码）。需要 ViaProxy 转换版本时，还要把 `[viaproxy] auth_method` 设为 `"ACCOUNT"`，并先运行一次 `java -jar runtime/viaproxy/ViaProxy.jar`，在图形界面的 Accounts 里登录。
- 离线模式（关闭正版验证）下名字可以被冒用：把世界开放到外网时，请给隧道或服务器设置访问密码、白名单。

## 选择大脑（四种模式）

在 `config.toml` 的 `[brain] mode` 里选一种：

| 模式 | 谁来思考 | 要密钥吗 | 费用 | 适合 |
|---|---|---|---|---|
| `"api"` | 她自己调用 Claude API | 要（或登录） | 按用量付费给 Anthropic | 想让她独立运行、效果最好 |
| `"openai"` | 她自己调用 GPT / DeepSeek / 通义千问 / 本地模型 | 要（本地模型不用） | 按用量付费给对应服务商 | 想用别家模型或省钱 |
| `"claude-code"` | 你开着的 Claude Code 会话 | 不要 | 用你的 Claude 订阅额度 | 有 Claude 订阅、一边改代码一边玩 |
| `"none"` | 不思考 | 不要 | 免费 | 只要快捷命令和自动行为 |

不管哪种模式，快捷命令（`#决斗` `#帮助` …）、陪伴、打怪、睡觉、捡东西这些自动行为都照常工作；大脑只影响她能不能听懂你随口说的话、接临时的活。

### Claude API（`mode = "api"`）

她独立运行，每次有人叫她时调用 Claude 思考。认证三选一（按这个顺序找，找到一个就用）：

1. 在 `[brain.api] api_key` 填控制台的 API Key（`sk-ant-` 开头）；
2. `api_key` 留空，设置环境变量 `ANTHROPIC_API_KEY`（更安全，分享配置文件也不会泄露）；
3. `api_key` 留空，用官方命令行 `ant auth login` 在浏览器登录 Claude 平台账号。

常用设置都在 `[brain.api]`：

- `model`：默认 `claude-opus-5-5`。
- `effort`：思考力度，`"low"` 更省钱。
- `max_episodes_per_hour`：每小时最多思考多少次，防止花费失控。
- `web_search`：允许联网查 Minecraft Wiki 和 MC百科，会产生额外的搜索费用，不需要可以关。
- `fallbacks`：请求被安全策略拒绝时，Anthropic 自动换推荐的备用模型重试（按备用模型的价格计费），不需要设 `false`。
- `base_url`：中转或代理地址。你的 API Key 会发给这个地址，请确认它可信。

配好后正常[启动](#启动与结束)即可。

### OpenAI 兼容接口（`mode = "openai"`）

她独立运行，调用 OpenAI 兼容的 Chat Completions 接口（要支持函数调用）。在 `[brain.openai]` 里选服务商：

| `provider` | 用的是 | 默认模型 | 密钥放哪 |
|---|---|---|---|
| `"openai"` | GPT | `gpt-5` | 环境变量 `OPENAI_API_KEY` |
| `"deepseek"` | DeepSeek（也可以直接写 `mode = "deepseek"`） | `deepseek-chat` | 环境变量 `DEEPSEEK_API_KEY` |
| `"custom"` | 通义千问、Kimi、智谱、本地 Ollama / LM Studio 等 | 自己填 `model` | 自己填 `base_url`；本机地址可以不要 Key |

密钥也可以直接填进 `api_key`，或者用 `api_key_env` 指定别的环境变量名，但放环境变量更安全。同样按用量计费，`max_episodes_per_hour` 限制每小时的思考次数。这种模式没有联网查资料和服务端备用模型，其他功能一样。配好后正常[启动](#启动与结束)即可。

### Claude Code（`mode = "claude-code"`）

她自己不思考，由你开着的 Claude Code 会话当她的大脑。不需要任何密钥：用的是 Claude Code 自己的登录（也就是你的 Claude 订阅），所以 `config.toml` 里没有密钥是正常的。

**怎么运转**

1. 她的程序在本机开一个控制接口（`127.0.0.1:3777`，只有本机能连）。每次启动都会随机生成令牌，保存在 `runtime/control.json`。
2. Claude Code 运行 `npm run ctl -- watch` 挂着监听，游戏里有人叫她、任务做完、有人上床这些事件都会实时传过去。
3. Claude Code 想好怎么回、怎么做以后，用 `npm run ctl -- say …`（说话）、`npm run ctl -- act …`（执行动作）让她在游戏里照做。

**怎么运行**

1. 把 `mode` 改成 `"claude-code"`（第一次运行问答时选 3 也行）。
2. 没装过 Claude Code 的，先装它（桌面应用或命令行版都行），并用你的 Claude 账号登录。
3. 在项目文件夹里打开 Claude Code：桌面应用里把工作目录选成项目文件夹；命令行里先进入项目文件夹，再运行 `claude`。
4. 对它说“按 CLAUDE.md 启动猫娘并接管”。它会在后台启动她、挂上监听，然后开始替她思考和说话。
   - 也可以先自己双击 `start.bat` 启动她，再让 Claude Code 挂上监听。不会开出两个她：已经有一个在跑时，第二个会提示后自动退出。
5. 不玩了：对 Claude Code 说“让猫娘下线”，或者自己运行 `npm run ctl -- stop`。

**注意**

- 只有 Claude Code 会话开着、监听挂着的时候，她才能听懂闲聊、接临时的活（比如“去给我挖点钻石”）。会话关了以后，快捷命令和自动行为照常，只是没人回她听到的闲聊。
- Claude Code 按 [CLAUDE.md](CLAUDE.md) 做事：游戏聊天里的话只当作玩家的请求，不会因为聊天内容去动电脑上别的文件；主人发的 `#需求` 会在后台改代码、测试、提交。

### 只挂机（`mode = "none"`）

不思考不聊天，但快捷命令、陪伴、自卫、睡觉邀请等自动行为照常工作。

## 启动与结束

### 启动

- **Windows**：双击 `start.bat`。它先把环境检查一遍（都准备好了一秒就过），然后启动她；窗口会一直开着显示她的状态。
- **命令行**：在项目文件夹里运行 `npm start`。
- **Claude Code 模式**：让 Claude Code 帮你启动，见上一节。

看到 `✓ 已进入世界` 就说明进服了，她会在聊天栏打招呼。

- **同一时间只能有一个她在跑**：两个同名的她会互相把对方挤下线。已经有一个在跑时，再启动会显示“猫娘已经在运行了”并自动退出，这是正常的。
- **自动重连**：世界关了、服务器重启时，她会自己隔一会儿重连（先等 15 秒，连不上逐渐拉长，最长 2 分钟），你重新开服后等一会儿她就进来了。想让她马上重连：`npm run ctl -- reconnect`。

### 结束

三种方式都会正常下线：

- 运行 `npm run ctl -- stop`（任何模式都可以）；
- 在 `start.bat` 的窗口里按 `Ctrl+C`，或者直接关掉窗口；
- Claude Code 模式下对 Claude Code 说“让猫娘下线”。

下线时她手上的任务会停下。如果正好在决斗，收尾的事（还背包、拆决斗场、送回原处）会记下来，下次上线自动补做。

### 重启

改了 `config.toml`、更新了代码之后需要重启：先按上面的方式结束，再重新启动。游戏里用 `#设置` 改的设置不用重启。

### 更新

- **下载压缩包的**：先让她下线，下载新的压缩包，解压覆盖到原来的文件夹（压缩包里没有 `config.toml` 和 `runtime/`，你的配置和她的记忆不会被覆盖），再双击 `start.bat`，依赖有变化时会自动重装。
- **用 git 的**：`git pull`，再启动（`start.bat` 同样会自动更新依赖；用 `npm start` 的先运行一次 `npm run setup`）。
- 想顺便更新 ViaProxy：运行 `npm run setup -- --update`。
- 面板模组有新版本时，关掉游戏运行 `npm run install-mod -- --game "…"`，再打开游戏。

## 在游戏里怎么用

发 `#帮助` 查看完整说明（可以点击命令），常用：

| 命令 | 作用 |
|---|---|
| `#状态` `#背包` `#好感` `#任务` | 查看她的状态、背包、好感度、正在做的事 |
| `#过来` `#跟着` `#停` `#回家` | 叫她过来、一直跟着、停下、回床边 |
| `#摸头` `#抱抱` `#跳舞` `#坐下` `#喵` | 互动动作 |
| `#猜拳 石头` `#猜数字` `#抛硬币` | 小游戏 |
| `#决斗` `#决斗 困难Ⅲ` `#认输` `#战绩` `#观战` | PVP 决斗（锁 1 滴血，不会打死） |
| `#菜单` | 弹出功能菜单（装了面板模组时也可以 Shift+右键她） |
| `#需求 …` `#需求` | 许愿要新功能 / 看处理进度（主人） |
| `#设置` `#设置 跳劈 关` `#设置 决斗场 家上空` | 在游戏里开关她的各种行为（主人） |

## 给她换皮肤

离线玩家没有正版皮肤，游戏会按 UUID 给她分配一张默认皮肤。用资源包替换那张默认皮肤即可，不需要任何模组：

```bash
npm run skin -- 你的皮肤.png --out "游戏目录/resourcepacks"
```

然后在游戏里：选项 → 资源包 → 把「NJFU猫娘皮肤」移到右边 → 完成。不给图片时使用自带的猫娘女仆皮肤 `assets/skins/neko-maid.png`。只有启用了这个资源包的玩家能看到。

## 命令行

她运行时，可以在项目文件夹里用这些命令查看和操作她：

```bash
npm run ctl -- help          # 所有命令
npm run ctl -- status        # 简短状态
npm run ctl -- context       # 完整上下文（Claude Code 模式用）
npm run ctl -- say 你好       # 让她说话（悄悄话加 --to 玩家名）
npm run ctl -- act goto x=100 y=64 z=-20   # 执行动作（actions 列出全部）
npm run ctl -- cancel        # 停下当前任务
npm run ctl -- watch         # 持续输出新事件
npm run ctl -- reconnect     # 立即重连
npm run ctl -- logs -f       # 实时查看日志
npm run ctl -- report        # 生成问题报告（密钥已打码）
npm run ctl -- stop          # 让她下线并退出
```

## 文件都放在哪

| 位置 | 内容 |
|---|---|
| `config.toml` | 主配置：服务器、名字、大脑模式、密钥、各种行为开关（不会上传到 git） |
| `config.example.toml` | 配置模板和默认值 |
| `runtime/overrides.json` | 游戏里用 `#设置` 改过的设置，优先于 config.toml |
| `runtime/memory.json` `affection.json` | 她的记忆、对每个人的好感 |
| `runtime/home.json` `chests.json` | 家（床）的位置、记住的箱子里有什么 |
| `runtime/duels.json` `duel-pending.json` | 决斗战绩、断线后待补的决斗收尾 |
| `runtime/logs/` | 运行日志（按天分文件，保留 14 天）、事件记录 |
| `runtime/viaproxy/` | ViaProxy 程序 |
| `runtime/trash/` | 挪开没删的旧文件 |
| 游戏目录 `config/njfu_neko_panel.json` | 面板模组的设置 |
| 世界存档 `njfu_neko_stash/` | 决斗时替玩家保管背包的存档 |

整个 `runtime/` 都不会上传到 git。要备份或者搬到别的电脑，拷走 `config.toml` 和 `runtime/` 就行，她的记忆、好感、战绩都会跟着走。

## 日志与排查问题

- 运行日志：`runtime/logs/neko-日期.log`；事件记录：`runtime/logs/events.jsonl`；ViaProxy 日志：`runtime/logs/viaproxy.log`。
- 出问题时运行 `npm run ctl -- report`，把生成的报告发给帮你排查的人，里面的 API Key 和令牌都已打码。

## 常见问题

- **连不上**：局域网端口每次开放可能不同（装 mcwifipnp 可以固定），核对 `config.toml` 的端口；确认开放时正版验证选了“禁用”；再看 `runtime/logs/` 里的日志。
- **被踢出，提示需要 Fabric API**：确认 `[compat] fabric_handshake = true`。
- **她每十几秒掉线一次**：多半是同时开了两个她（比如开着一个又双击了 `start.bat`）。新版本已经会自动拦住第二个；还有问题就先 `npm run ctl -- stop`，再只启动一个。
- **启动时说“猫娘已经在运行了”**：说明已经有一个在跑，不用再开。要重启就先 `npm run ctl -- stop`。
- **进不了 Forge 整合包服务器**：她用的是原版协议，Forge 服务器会先核对客户端装了哪些模组，有大量内容模组的整合包会直接拒绝。目前只支持原版和 Fabric（带 Fabric API）的服务器。
- **ViaProxy 启动失败**：检查 Java 版本（17+），或在 `[viaproxy] java` 填 java.exe 的完整路径；看 `runtime/logs/viaproxy.log`。
- **管理员聊天栏里出现灰色的 [NJFU_Neko: …]**：那是原版的“管理员命令广播”。装上面板模组后，她的命令都会静默执行，不再留下灰色提示；不推荐为此关掉 `send_command_feedback`，那会连所有人自己执行命令的提示一起关掉。
- **皮肤没变**：确认资源包已经在游戏里启用（移到右边“已选”一栏）。

## 安全

- API Key（Claude、OpenAI、DeepSeek 等）读取后会从内存里的配置和环境变量中清除，不会传给 ViaProxy；所有日志、事件、聊天输出都会自动打码；`config.toml` 被 git 跟踪时启动会警告。
- 控制接口只监听 127.0.0.1，要求随机令牌，并拒绝浏览器发来的请求；执行任意代码的 eval 默认关闭。
- 玩家在聊天里说的话只会被当作游戏里的请求；/ 命令分级管理，`stop`、`op`、`ban` 等永远不执行。
