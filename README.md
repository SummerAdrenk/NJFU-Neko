# NJFU智慧猫娘

一个能像玩家一样进入 Minecraft 的 AI 猫娘伙伴：会陪你冒险、听你在聊天栏的吩咐干活、和你聊天互动，大脑由 Claude 驱动（也能接 GPT、DeepSeek 等 OpenAI 兼容接口）。

- 支持新版本服务器（包括 26.2 这样 mineflayer 还没支持的版本）：自动经 ViaProxy 转换协议。
- 支持装了 Fabric API 的服务器和局域网世界：自动完成 Fabric 注册表同步握手。
- 几种大脑：直接调用 Claude API 独立运行；调用 OpenAI 兼容接口（GPT、DeepSeek、通义千问、本地 Ollama 等）独立运行；或者由 Claude Code 会话来“附身”操作。

## 她能做什么

- **聊天**：聊天里带上「猫娘」就能叫她；私聊也行。中文口语，偶尔带「喵」。
- **干活**：采集、合成（会自己规划合成树）、熔炼、存取箱子、运送物资、跟随、护卫、打怪、建造、驯服动物。
- **自己动**：没事时陪在主人身边走动；捡掉落物；缺装备和食物时去箱子里拿，闲着时翻看附近没看过的箱子，背包快满时自己扔垃圾（不扔礼物和附魔的东西）；受伤时把饱食度吃满来回血，没吃的先翻箱子、再问主人能不能去打猎；离太远自动传送回来。
- **战斗技巧**：跳劈暴击、蓄满再出手、保持距离、身边有人时不横扫；用盾牌挡箭、挡近战、挡苦力怕爆炸；打不过的近战怪放船困住再打（不打船，打完收船）；弓箭和雪球自动算弹道；苦力怕打了就跑、恶魂反弹火球；有岩浆桶就先把够得着的怪都烫一遍再砍（放下马上收回，困难以上）；被怪群围住用水桶冲开、垫方块躲上去，只剩 1 滴血才撤；打斗间隙吃东西，半血喝药水、吃金苹果，不死图腾换到副手；药水分给自己、给你（你血少时往你身上扔治疗）、砸怪（亡灵用治疗药水）；被激怒的末影人会主动处理；日常索敌 32 格（末影龙、凋灵、恶魂例外）；主人同意时打末影龙、凋灵。战斗模式分普通 / 困难 / 极限（还会鞘翅撤离）/ 作弊（临时发顶级附魔装备，切回来收回），发 `#战斗模式` 切换。
- **出行**：平时走路不放方块，被困住走不出去时才垫方块搭桥、爬高（临时放的工作台、熔炉用完收回）；从高处掉下来会落地前倒水、鞘翅滑翔或者放船坐进去；有鞘翅和烟花能飞；穿传送门（主人穿过去她会跟上）；和主人一起坐船、坐骆驼，也能坐矿车、骑马。
- **懂规矩**：不打挂了命名牌的生物、坐在船或矿车里的生物（多半在刷怪机器里）和禁战区里的生物，但骑在别的生物身上的怪（蜘蛛骑士、鸡骑士等）照打，先打骑手；/ 命令分级管理；只替主人执行管理员命令。
- **红石与建造**：读出一片区域里每个红石元件的状态来排查故障；按方块状态建造；照投影（Litematica）原理图建造。建造前先备料：背包够就直接建，箱子里够会先问你要不要拿，都不够就自己采集、合成（工作台、熔炉、镐子也自己做）；你明确说“用命令建”才用 /setblock。
- **查资料**：本地游戏数据（配方、来源、方块和生物资料）、Minecraft 中文 Wiki；API 模式还能联网查 MC百科。用 /locate 找结构，并附 Chunkbase 地图链接。
- **互动与娱乐**：好感度系统、摸头、抱抱、跳舞、坐下、捡木棍游戏、猜拳、猜数字、钓鱼、PVP 决斗（简单、普通、困难Ⅰ～Ⅵ、作弊Ⅰ～Ⅵ：装备从铁套到顶级附魔下界合金，招式从普通砍到剑斧切换、蜘蛛网、鞘翅俯冲、末影珍珠瞬移、末影水晶和 TNT；装备都是临时的，默认给对手也穿一套；默认在原地正上方（y=200 起）现搭 100×100 的空中黑曜石决斗场，四周屏障墙到顶；搭之前把那一片扫一遍，不会盖住任何方块，打完拆掉、送回原处（`#设置 决斗场` 可改成家上空或不用）；所有难度强制锁 1 滴血，谁都不会被打死；一局最长 15 分钟、作弊档 30 分钟，屏幕上方有倒计时，最后 1 分钟提醒，随时可以 #认输；决斗中右键她不会打开背包；别的玩家发 #观战 以旁观者模式去看，打完自动回来）；有人上床时问要不要一起睡，答应了就陪到天亮（被打醒先把床边的怪打掉再回床上），也可以直接说「睡觉」；玩家上线问候、死亡关心、进度祝贺。
- **识别模组**：进服时从频道、命令、标签里识别服务器装了哪些模组（例如 Carpet），并使用它们的命令。
- **在游戏里查看她**：装了面板模组时**右键她**打开人物面板（她的模型、盔甲、副手、背包），可以直接拿放东西；**Shift+右键**打开功能菜单。没装模组时用 `#背包` `#菜单` `#状态` 等快捷命令。
- **在游戏里许愿和设置**：主人发 `#需求 …` 提新功能（Claude Code 模式下由后台处理，见 CLAUDE.md），`#设置` 直接开关她的各种行为。

## 工作原理

```
你的 Minecraft（例如 26.2 局域网世界）
        ▲
        │  26.2 协议
   ViaProxy（协议转换，自动启动）
        ▲
        │  26.1 协议
   猫娘本体（Node.js + mineflayer）── 控制接口 127.0.0.1:3777 ── 命令行 / Claude Code
        │
   大脑：Claude API（独立模式）或 Claude Code 会话
```

## 准备

- Node.js 20 或更高版本
- Java 17 或更高版本（ViaProxy 需要；服务器版本 mineflayer 直接支持时用不到）
- 一个服务器或开了局域网的单人世界

```bash
npm install
npm run setup
```

`npm run setup` 会检查 Node 和 Java、从 GitHub 下载最新的 ViaProxy，并生成 `config.toml`。用记事本打开 `config.toml`，按注释修改：服务器地址和端口、大脑模式、主人名单等。

Windows 上也可以直接双击 `start.bat`：第一次运行会自动安装依赖、下载 ViaProxy、生成配置。

## 启动

```bash
npm start
```

或双击 `start.bat`。

### 连局域网单人世界

1. 在游戏里“对局域网开放”：记下端口（装了 mcwifipnp 可以固定端口），**正版验证选“禁用”**（猫娘是离线账号），**允许命令**打开。
2. 把端口填进 `config.toml` 的 `[server] port`。
3. 启动猫娘，她进来后在聊天栏输入 `/op NJFU_Neko` 给她管理员权限（说话变好看、能用命令、能显示前缀）。

### 连服务器

- 正版服务器：`[account] auth = "microsoft"`，第一次启动按提示在浏览器登录微软账号（不用写密码）。服务器版本需要 ViaProxy 转换时，还要把 `[viaproxy] auth_method` 设为 `"ACCOUNT"`，并先运行一次 ViaProxy 图形界面（`java -jar runtime/viaproxy/ViaProxy.jar`）登录账号。
- 上服务器前一定要填 `[chat] owners` 主人名单，并确认服务器规则允许机器人。
- 离线模式（关闭正版验证）下名字可以被冒用：把世界开放到外网时，请给隧道/服务器设置访问密码或白名单。

## 大脑

### Claude API（`[brain] mode = "api"`）

猫娘独立运行，每次有人叫她时调用 Claude API 思考。认证方式三选一：

1. 在 `config.toml` 的 `[brain.api] api_key` 填控制台的 API Key；
2. 设置环境变量 `ANTHROPIC_API_KEY`（更安全）；
3. 用官方命令行 `ant auth login` 在浏览器登录 Claude 平台账号。

说明：

- **按用量计费**。简单对话每次只需很少的费用，干复杂的活会多一些；可以用 `effort = "low"` 降低成本，`max_episodes_per_hour` 限制每小时的思考次数。
- 默认开启了**拒绝时自动换备用模型**（服务端 `fallbacks: "default"`）：请求被安全策略拒绝时，Anthropic 会自动用推荐的备用模型重试，按备用模型的价格计费。不需要时设 `fallbacks = false`。
- 默认允许大脑联网查 Minecraft Wiki 和 MC百科（`web_search`），会产生额外的搜索费用，不需要可以关闭。
- 用中转/代理地址（`base_url`）时，你的 API Key 会发给那个地址，请确认它可信。

### OpenAI 兼容接口：GPT、DeepSeek 等（`[brain] mode = "openai"`）

猫娘独立运行，调用 OpenAI 兼容的 Chat Completions 接口（要支持函数调用）。在 `[brain.openai]` 里选服务商：

- `provider = "openai"`：GPT，默认模型 `gpt-5`，Key 放环境变量 `OPENAI_API_KEY`；
- `provider = "deepseek"`：DeepSeek，默认模型 `deepseek-chat`，Key 放环境变量 `DEEPSEEK_API_KEY`（也可以直接写 `mode = "deepseek"`）；
- `provider = "custom"`：通义千问、Kimi、智谱、本地 Ollama / LM Studio 等，自己填 `base_url` 和 `model`（本机地址可以不要 Key）。

Key 也可以填在 `api_key` 里，但放环境变量更安全。同样按用量计费（由对应的服务商收费），`max_episodes_per_hour` 限制每小时的思考次数。这种模式没有联网查资料（MC百科）和服务端备用模型，其他功能一样。

### Claude Code（`[brain] mode = "claude-code"`）

在本项目目录打开 Claude Code，它会按 [CLAUDE.md](CLAUDE.md) 启动猫娘、监听聊天，并通过命令行替她说话和行动。适合想用 Claude 订阅账号、或者一边开发一边玩的情况。

### 只挂机（`mode = "none"`）

不思考不聊天，但快捷命令、陪伴、自卫、睡觉邀请等自动行为照常工作。

## 人物面板模组（可选，推荐）

`mod/dist/njfu-neko-panel-*.jar` 是一个很小的 Fabric 模组，放进游戏的 `mods` 文件夹（需要 Fabric API），重启游戏后：

- **右键猫娘**：打开她的人物面板——左边盔甲、中间她的模型、副手，下面是她的背包和快捷栏，再下面是你自己的背包，直接拖动就能拿放。只有主人能拿放，其他人只能看（在游戏目录的 `config/njfu_neko_panel.json` 里设置）。
- **Shift+右键**：她给你弹出功能菜单，按钮点一下就生效（模组 1.0.2 起；没装模组时按钮会先弹原版的确认窗口，选「复制到聊天屏幕」再按回车）。
- 她执行的传送、特效、弹窗等命令不再在管理员聊天栏里留下灰色提示。

单人和局域网世界装在自己的游戏里就行；服务器要装在服务器上。没装模组的玩家右键她看到的是普通的 5 行物品界面，一样能用。自己编译：`npm run build-mod -- --game "<.minecraft>/versions/<版本名>" --jdk <JDK目录>`（不需要 Gradle）。

## 在游戏里怎么用

发 `#帮助` 查看完整说明（可以点击命令），常用：

| 命令 | 作用 |
|---|---|
| `#状态` `#背包` `#好感` `#任务` | 查看她的状态、背包、好感度、正在做的事 |
| `#过来` `#跟着` `#停` `#回家` | 叫她过来、一直跟着、停下、回床边 |
| `#摸头` `#抱抱` `#跳舞` `#坐下` `#喵` | 互动动作 |
| `#猜拳 石头` `#猜数字` `#抛硬币` | 小游戏 |
| `#决斗` `#决斗 困难` `#认输` `#战绩` | PVP 决斗（默认切磋，不会打死） |
| `#菜单` | 弹出功能菜单（装了面板模组时也可以 Shift+右键她） |
| `#需求 …` `#需求` | 许愿要新功能 / 看处理进度（主人） |
| `#设置` `#设置 跳劈 关` | 在游戏里开关她的各种行为（主人） |
| `#战斗模式` `#战斗模式 极限` `#战斗模式 作弊 钻石` | 切换战斗模式（主人） |

其他事情直接用中文说就行：「猫娘去挖 32 个圆石」「猫娘做一把铁镐」「猫娘把钻石运给我」「猫娘最近的村庄在哪」「猫娘看看这台刷铁机哪里坏了」「猫娘上我的船」「猫娘驯服一只狼送给我」「猫娘去下界」。

## 给她换皮肤

离线玩家没有正版皮肤，游戏会按 UUID 给她分配一张默认皮肤。用资源包替换那张默认皮肤即可，不需要任何模组：

```bash
npm run skin -- 你的皮肤.png --out "游戏目录/resourcepacks"
```

然后在游戏里：选项 → 资源包 → 把「NJFU猫娘皮肤」移到右边 → 完成。不给图片时使用自带的猫娘女仆皮肤 `assets/skins/neko-maid.png`。细手臂和粗手臂皮肤会自动转换。只有启用了资源包的玩家能看到。

## 命令行

```bash
npm run ctl -- help        # 所有命令
npm run ctl -- status      # 状态
npm run ctl -- say 你好     # 让她说话
npm run ctl -- act goto x=100 y=64 z=-20
npm run ctl -- logs -f     # 实时查看日志
npm run ctl -- report      # 生成问题报告（密钥已打码）
```

## 日志与排查问题

- 运行日志：`runtime/logs/neko-日期.log`（按天分文件，保留 14 天）。
- 事件记录：`runtime/logs/events.jsonl`；ViaProxy 日志：`runtime/logs/viaproxy.log`。
- 出问题时运行 `npm run ctl -- report`，把生成的报告发给帮你排查的人，里面的 API Key 和令牌都已打码。

## 安全

- API Key（Claude、OpenAI、DeepSeek 等）读取后会从内存里的配置和环境变量中清除，不会传给 ViaProxy；所有日志、事件、聊天输出都会自动打码；`config.toml` 被 git 跟踪时启动会警告。
- 控制接口只监听 127.0.0.1，要求随机令牌，并拒绝浏览器发来的请求；执行任意代码的 eval 默认关闭。
- 玩家在聊天里说的话只会被当作游戏里的请求；/ 命令分级管理，`stop`、`op`、`ban` 等永远不执行。

## 常见问题

- **被踢出，提示需要 Fabric API**：确认 `[compat] fabric_handshake = true`。
- **连不上**：局域网端口每次开放可能不同（装 mcwifipnp 可以固定），核对 `config.toml` 的端口；看 `runtime/logs/` 里的日志。
- **管理员聊天栏里出现灰色的 [NJFU_Neko: …]**：那是原版的“管理员命令广播”，由游戏规则 `send_command_feedback` 控制（`log_admin_commands` 只管服务器日志）；关掉 `send_command_feedback` 会连所有人自己执行命令的提示一起关掉，不推荐。装上面板模组后，猫娘的命令都会静默执行，不再留下灰色提示；没装时她只在必要时用命令（传送、坐下等），爱心粒子和猫叫声这类特效不会播放。
- **皮肤没变**：确认资源包已经在游戏里启用（移到右边“已选”一栏）。
- **ViaProxy 启动失败**：检查 Java 版本（17+），或在 `[viaproxy] java` 填 java.exe 的完整路径；看 `runtime/logs/viaproxy.log`。
